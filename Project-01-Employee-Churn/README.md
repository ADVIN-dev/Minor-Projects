# Delhi Metro Data Analysis (EDA)

## Overview

This project performs **Exploratory Data Analysis (EDA)** on the Delhi Metro dataset containing over **85,000 trip records**. The objective is to understand travel patterns, clean the dataset, generate business insights, and prepare the data for future machine learning applications.


## Dataset Information

The dataset contains information such as:

* Trip ID
* Date
* From Station
* To Station
* Distance Travelled
* Fare
* Cost per Passenger
* Number of Passengers
* Ticket Type
* Remarks


## Objectives

* Perform data cleaning
* Handle missing values
* Remove inconsistencies
* Explore passenger behaviour
* Analyze fare distribution
* Identify station usage patterns
* Prepare the dataset for machine learning


## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn


## Project Workflow

1. Data Loading
2. Data Cleaning
3. Handling Missing Values
4. Exploratory Data Analysis
5. Feature Engineering
6. Label Encoding
7. Standard Scaling
8. Business Insights


## Business Questions Solved

* Which ticket type generates the highest revenue?
* Which stations are most frequently used?
* Is there a relationship between fare and distance?
* How are passengers distributed across trips?


## Key Findings

* Most metro trips are shorter than 10 km.
* Fare increases with travel distance.
* Passenger counts remain fairly consistent.
* Feature engineering improved the dataset for future ML models.
