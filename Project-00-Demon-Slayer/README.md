# Demon Slayer Character Data Analysis (EDA)

*Note: 

This was my first Exploratory Data Analysis (EDA) project, created while learning the fundamentals of data preprocessing and visualization. 
It marks the beginning of my Machine Learning learning journey.


## Overview

This project performs Exploratory Data Analysis (EDA) on a Demon Slayer character dataset.
The objective was to explore the dataset, clean missing values, analyze relationships between different character attributes, and visualize key patterns using Python.


## Dataset

The dataset contains information about Demon Slayer characters, including:

- Character ID
- Age
- Weight
- Race
- Status
- Role
- Voice Actors
- Enemies
- Other character-related features


## Objectives

- Perform data cleaning
- Handle missing values
- Remove duplicate records
- Detect and treat outliers
- Perform Exploratory Data Analysis
- Understand relationships between different character attributes


## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn


## Project Workflow

1. Data Loading
2. Data Cleaning
3. Missing Value Handling
4. Duplicate Check
5. Outlier Detection
6. Exploratory Data Analysis
7. Correlation Analysis
8. Data Visualization


## Key Insights

- Missing values were identified and handled appropriately.
- Outliers were detected and treated using the IQR method.
- Relationships between numerical features were explored using correlation analysis.
- Various visualizations helped identify patterns among character attributes.
