# Heart Failure Patient Clustering using K-Means

## Overview

This project applies K-Means Clustering to group heart failure patients into different clusters based on their medical records. Since the dataset does not contain predefined labels, an unsupervised machine learning approach was used to discover meaningful patient groups.


## Dataset

The dataset contains medical information such as:

- Age
- Ejection Fraction
- Serum Creatinine
- Platelets
- Serum Sodium
- Blood Pressure
- Other clinical features


## Objectives

- Explore and understand the dataset
- Scale numerical features
- Determine the optimal number of clusters
- Apply K-Means Clustering
- Visualize patient clusters
- Interpret clustering results


## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn


## Project Workflow

1. Data Loading
2. Data Exploration
3. Feature Scaling

6. K-Means Clustering
7. Cluster Visualization
8. Cluster Interpretation


## Model Evaluation

- Elbow Method
- Silhouette Score
- Cluster Visualization


## Key Insights

- Patients were grouped into three meaningful clusters.
- Similar medical characteristics were observed within each cluster.
- Cluster analysis can help identify different patient risk groups.
- K-Means effectively discovered hidden patterns in healthcare data.
