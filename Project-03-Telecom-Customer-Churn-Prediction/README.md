# Telecom Customer Churn Prediction using Machine Learning

## Overview

This project focuses on predicting customer churn for a telecom company using Machine Learning. By analyzing customer demographics, account information, and service usage patterns, the model identifies customers who are likely to discontinue the service.


## Dataset

The dataset contains customer information such as:

- Gender
- Senior Citizen Status
- Tenure
- Monthly Charges
- Total Charges
- Contract Type
- Payment Method
- Internet Service
- Service-related Features
- Churn (Target Variable)


## Objectives

- Explore the dataset through Exploratory Data Analysis (EDA)
- Clean and preprocess the data
- Encode categorical variables
- Scale numerical features
- Build a Machine Learning classification model
- Evaluate model performance


## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn


## Project Workflow

1. Data Loading
2. Exploratory Data Analysis
3. Data Cleaning
4. Feature Encoding
5. Feature Scaling
6. Train-Test Split
7. Logistic Regression Model
8. Model Evaluation


## Model Evaluation

- Accuracy Score
- Confusion Matrix
- Classification Report


## Key Insights

- Customer demographics and service-related features influence churn.
- Proper preprocessing improves model performance.
- Logistic Regression provides a reliable baseline model for customer churn prediction.
- The model can help businesses identify at-risk customers and support customer retention strategies.
