# Deep Learning Fundamentals with TensorFlow

## Overview

This project introduces the fundamentals of Deep Learning using **TensorFlow**, **Keras**, and **Streamlit**. It includes multiple practical implementations covering neural networks, medical data classification, image classification, and deploying a simple interactive application using Streamlit.

The objective of this project was to understand the complete deep learning workflow—from building neural networks to creating an interactive user interface for Python applications.


## Topics Covered

### 1. Neural Network Fundamentals

- Building a basic neural network using TensorFlow
- Understanding model architecture
- Model training and prediction

### 2. Artificial Neural Network (ANN)

- Data preprocessing
- Feature scaling
- Binary classification
- Model evaluation

### 3. Convolutional Neural Network (CNN)

- Image preprocessing
- CIFAR-10 image classification
- CNN architecture
- Model training and evaluation

### 4. Streamlit Application

- Developed a simple interactive Greeting App
- Used Streamlit widgets such as:
  - Text Input
  - Select Box
  - Slider
  - Buttons
  - Progress Bar
  - Success, Warning & Info Messages
- Created a clean and user-friendly interface
- Learned the basics of deploying Python applications using Streamlit
