# Deep Learning Fundamentals with TensorFlow

## Overview

This project introduces the fundamentals of Deep Learning using TensorFlow and Keras. 
It includes multiple practical implementations covering neural networks, medical data classification, and image classification using Convolutional Neural Networks (CNNs).
The objective of this project was to understand the workflow of building, training, and evaluating deep learning models across different problem domains.


## Topics Covered

### 1. Neural Network Fundamentals

- Building a basic neural network using TensorFlow
- Understanding model architecture
- Training and prediction

### 2. Breast Cancer Classification using ANN

- Data preprocessing
- Feature scaling
- Artificial Neural Network (ANN)
- Model evaluation

### 3. Image Classification using CNN

- Convolutional Neural Networks (CNN)
- CIFAR-10 image dataset
- Image preprocessing
- Model training and evaluation
