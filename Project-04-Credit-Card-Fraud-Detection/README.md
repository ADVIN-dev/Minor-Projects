# Credit Card Fraud Detection using Machine Learning

## Overview

This project focuses on detecting fraudulent credit card transactions using Machine Learning. A Gradient Boosting Classifier was trained to distinguish between genuine and fraudulent transactions through data preprocessing, feature engineering, model training, and performance evaluation.


## Dataset

The dataset contains transaction-related information including:

- Transaction Details
- Numerical Features
- Categorical Features
- Target Variable (IsFraud)


## Objectives

- Perform Exploratory Data Analysis (EDA)
- Clean and preprocess the dataset
- Encode categorical features
- Train a Machine Learning classification model
- Optimize model performance using Hyperparameter Tuning
- Compare multiple Machine Learning models


## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn


## Project Workflow

1. Data Loading
2. Exploratory Data Analysis
3. Data Preprocessing
4. Label Encoding
5. Train-Test Split
6. Gradient Boosting Classifier
7. Hyperparameter Tuning
8. Model Evaluation
9. Model Comparison


## Model Evaluation

- Accuracy Score
- Confusion Matrix
- Classification Report


## Key Insights

- Gradient Boosting achieved high prediction accuracy for fraud detection.
- Hyperparameter tuning improved model performance.
- Feature analysis identified the most influential transaction attributes.
- Model comparison showed that both Gradient Boosting and Random Forest performed exceptionally well.
