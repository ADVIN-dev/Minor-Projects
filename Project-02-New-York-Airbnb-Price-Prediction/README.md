# New York Airbnb Price Prediction using Machine Learning

## Overview

This project focuses on predicting Airbnb listing prices in New York using Machine Learning. The dataset was cleaned, analyzed, and preprocessed before training a Linear Regression model to estimate listing prices based on different property features.


## Dataset

The dataset contains Airbnb listings in New York along with information such as:

- Price
- Neighbourhood
- Room Type
- Minimum Nights
- Number of Reviews
- Availability
- Reviews Per Month
- Host Information


## Objectives

- Clean and preprocess the dataset
- Handle missing values and duplicate records
- Detect and treat outliers
- Perform Exploratory Data Analysis (EDA)
- Apply feature encoding
- Train a Machine Learning model
- Evaluate model performance


## Technologies Used

- Python

- Matplotlib
- Seaborn
- Scikit-learn


## Project Workflow

1. Data Loading
2. Data Cleaning
3. Missing Value Handling
4. Outlier Detection & Treatment
5. Exploratory Data Analysis
6. Correlation Analysis
7. Feature Encoding
8. Train-Test Split
9. Linear Regression Model
10. Model Evaluation


## Model Evaluation

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score
- Residual Analysis


## Key Insights

- Missing values and outliers significantly affected prediction quality.
- Proper preprocessing improved model performance.
- Property characteristics such as room type, neighbourhood, and availability influence listing prices.
- Linear Regression provides a useful baseline model for price prediction.
